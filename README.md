# Aaditya Patil Portfolio

Open `index.html` in a browser. Internet access is needed for Google Fonts and the GSAP CDN; the site also has a small fallback if GSAP does not load.

## Personalise before publishing
- Replace `your-email@example.com` in `index.html`.
- Replace the LinkedIn, GitHub and Instagram profile URLs in `index.html`.
- Update each project's `url` in the `projects` array in `js/script.js`. `#` entries are deliberate placeholders.
- Update project names/descriptions and About details as needed.

No PHP is needed because this is a static portfolio homepage.
